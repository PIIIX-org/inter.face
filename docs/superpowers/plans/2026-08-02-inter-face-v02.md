# inter.face v0.2 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: superpowers:subagent-driven-development for the build tasks. Phases 1 and 6 run in the MAIN session (human gates; push). Steps use checkbox (`- [ ]`) syntax.

**Goal:** Prove the pipeline by running it, close the construction-layer gap and the remaining research gaps, settle the 3× cost question from live data, and ship v0.2.0.

**Architecture:** Six phases in dependency order. The dogfood run comes first because it converts every later question from theoretical to observed: where the construction gap bites, what the 3× cost feels like, which loop steps an agent actually stumbles on. Research folds into existing files — **no new files** unless a phase proves one is unavoidable.

**Tech stack:** markdown, `scripts/check.sh`, headless browser for research, image-gen MCPs for the run.

## Global Constraints

- Everything from v1 still binds: sourcing rule (quotes trace to `docs/research/`, read off rendered pages), no placeholders, `§N` conventions, ≤200-line resident budget, no subject-indexed catalogs, page/tool fork in every reference file, Apple numbers as default+minimum pairs.
- **No file grows without earning it.** Every fold states what it displaced or why net-new lines are cheaper than a second file. The impeccable recomposition warning still governs.
- **The run is evidence.** Everything the dogfood run surfaces gets a ledger entry — observed, not recalled — before it becomes a fix.
- Commits as Taha-Mahmoodi; push only from the main session after `ALL CHECKS PASS`.

## Phase 3 — The construction layer (research → fold)

The confirmed zero-mention gap: the plugin demands numbers but teaches no method for deriving them. One research pass, browser-verified where primary sources exist, honestly labeled method-knowledge where they do not (Utopia, Material elevation, W3C oklch() are real sources; "how designers pick a ratio" is craft consensus and gets labeled as such — the ACCESS.md §6 precedent).

- [ ] **3.1** Research `docs/research/construction-verified.md`: **OKLCH mechanics** (neutral ramp from a sampled accent, chroma/lightness across a scale, P3/sRGB gamut clipping — W3C spec + browser-tested values); **type scale** (modular ratios and when each, measure 45–75ch with its evidence, line-height as f(size, measure), `clamp()` construction); **spacing** (4/8pt grids, relation to type scale, the baseline grid `CRAFT.md` references but never defines); **elevation** (multi-layer shadow construction, ambient+key, elevation as a system — Material's elevation docs are primary); **grid derivation** (columns/gutters/margins per breakpoint — the `DIRECTION.md` schema demands them).

## Self-review

Every v1 carried-item has a home: 3× (2.3), SKIPS writer (5.1), drift pair (5.2), EN 301 549 (4.1), live regions (4.1), aspect ratio (5.1), screen-flow (5.1). No new files except CHANGELOG and the research docs. Nothing in the plan re-litigates a v1 decision without new evidence.
